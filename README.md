# Lumora — Developer Portfolio

A premium dark personal developer portfolio built with **React 19, TypeScript, Vite, Motion and Lucide icons**, inspired by the restrained motion and polish of Magic UI. Original source code; not a copy of the Magic UI Next.js template.

## Development

```bash
npm install
npm run dev
npm run build
npm run preview
```

This project is being built on the `development` branch. The `main` branch has only an initialization README. **Do not deploy or merge before review.**

## Sections
- Hero and introduction
- Selected GitHub project highlights
- Skills and services
- About and contact
- Responsive navigation and accessible reduced-motion behavior

## Before launch
- Replace abstract project cover designs with permission-approved screenshots.
- Verify client claims, authorship and detailed outcomes.
- Add individual case-study routes, CV and professional headshot if desired.
- Confirm email and social links, review legal/privacy details, run Lighthouse and accessibility audits.
- Connect a deployment target only after approval.
